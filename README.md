## วิธีเล่น

หน้าจอแบ่งเป็น 3 ส่วน: **deck ปักหมุดบน** (transport · แทร็ค · step grid — ไม่หายไปไหน) →
**หน้าเนื้อหาเลื่อนได้ตรงกลาง** → **แท็บล่างจอ**

| | |
|---|---|
| **แท็บ** | VOICE · STEP · FX · MIX · BANK |
| **แทร็ค** | `303 · BD · SD · CH · OH · CP` — เลือกแล้วทั้ง grid และหน้า VOICE เปลี่ยนตาม |
| **303 · PITCH** | แตะช่องว่าง = เปิดโน้ต · แตะช่องที่ติด = เลือกไว้แก้ (เด้งไปหน้า STEP ให้) · แตะซ้ำ = ปิด |
| **303 · TIME** | แตะวน `— → ● → ○` (rest → note → tie) ตรงตามแผ่น pattern ของ Roland |
| **กลอง** | แตะครั้งเดียว วน ปิด → เปิด → เปิด+accent |
| **Length** | ตั้งความยาว pattern 1–16 step |
| **▲** | พับ grid เก็บเมื่อหน้าล่างต้องการที่ |
| **Clr** (หน้า STEP) | ล้างแทร็คปัจจุบัน · กดซ้ำภายใน 5 วิ = undo |
| **Bank** | 8 ช่องเก็บ pattern · แตะ = โหลด · Save = เก็บทับ · แตะช่องเดิมซ้ำภายใน 5 วิ = undo |
| **Delay** (หน้า FX) | insert บนเสียง 303 · sync กับ tempo · เริ่มต้น Mix=0 (ปิด) |

state ทั้งหมดถูกเข้ารหัสลง URL อัตโนมัติ — ก๊อป URL = ก๊อปเพลง

> ⚠️ **Bank เก็บในเบราว์เซอร์เครื่องนั้น** ล้างข้อมูลเว็บแล้วหายหมด
> กด **Export** เก็บไฟล์ JSON ไว้เป็นระยะ — นั่นคือ backup ตัวจริง

## กรอก pattern จากแผ่น TB-303

แผ่น pattern ของ Roland มีสี่แถว เรารองรับตรงตัว:

| แถวในแผ่น | ในแอป |
|---|---|
| `● ○ —` (แถวล่างสุด) | TIME mode |
| Note | PITCH mode — ใส่ได้เฉพาะช่อง `●` เหมือนเครื่องจริง |
| Accent / Slide | ปุ่มใน Step editor |
| Down / Up | ปุ่ม ▲▼ ข้างคีย์บอร์ด |

ลำดับที่เร็วที่สุดคือทำแบบเดียวกับเครื่องจริง — ไล่แถวจังหวะให้ครบใน TIME mode ก่อน แล้วค่อยกลับมาใส่พิตช์

## เทสต์

```bash
bash test/run.sh
```

ไม่ต้องติดตั้งอะไร ใช้ Node เปล่าๆ · **รันก่อน commit ทุกครั้ง** เทสต์พวกนี้เคยจับบั๊กที่ทำให้หน้าตายเงียบๆ มาแล้วสองรอบ

- `smoke.js` — eval สคริปต์ทั้งก้อนกับ DOM ปลอม จับ error ตอน boot
- `test_dsp.js` — เสียงแต่ละ voice, choke, time data, pattern length, CPU, knob sweep, worklet serialization
- `hash_test.js` — บันทึก/อ่าน URL ทุกเวอร์ชัน รวมลิงก์เก่า
- `bank_test.js` — bank, slot round-trip, ไฟล์ import ที่พัง
- `ui_test.js` — โครง DOM: id ครบไม่ซ้ำ · deck มีของที่ต้องปักหมุด · page/tab ตรงกัน
