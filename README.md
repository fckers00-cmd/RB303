# RB-303 → Acid Box

เครื่องดนตรีเล่นบนเบราว์เซอร์ — TB-303 หนึ่งตัว + กลองสังเคราะห์สไตล์ 808 ห้าเสียง
อยู่ในไฟล์ HTML ไฟล์เดียว ไม่มี build step ไม่มี dependency ไม่มี `eval`

เป็นโปรเจกต์ส่วนตัวเพื่อ**เรียนรู้ DSP** ไม่ใช่ product

---

## เปิดใช้

เปิด `rb303.html` ในเบราว์เซอร์ได้เลย

> ⚠️ เปิดจาก `file://` เบราว์เซอร์จะบล็อก AudioWorklet แล้วตกไปใช้ ScriptProcessor แทน
> เสียงยังออกปกติแต่ latency สูงกว่า · จะได้ worklet เต็มๆ ต้อง host บน https
> (แถบสถานะในแอปบอกอยู่ว่ากำลังใช้ engine ไหน)

## วิธีเล่น

| | |
|---|---|
| **แทร็ค** | `303 · BD · SD · CH · OH · CP` — เลือกแล้วทั้ง step grid และ panel Voice เปลี่ยนตาม |
| **303 · PITCH mode** | แตะช่องว่าง = เปิดโน้ต · แตะช่องที่ติด = เลือกไว้แก้ · แตะซ้ำ = ปิด |
| **303 · TIME mode** | แตะวน `— → ● → ○` (rest → note → tie) ตรงตามแผ่น pattern ของ Roland |
| **กลอง** | แตะครั้งเดียว วน ปิด → เปิด → เปิด+accent |
| **Length** | ตั้งความยาว pattern 1–16 step |
| **Clr** | ล้างแทร็คปัจจุบัน · กดซ้ำภายใน 5 วิ = undo |

state ทั้งหมดถูกเข้ารหัสลง URL อัตโนมัติ — ก๊อป URL = ก๊อปเพลง

## กรอก pattern จากแผ่น TB-303

แผ่น pattern ของ Roland มีสี่แถว เรารองรับตรงตัว:

| แถวในแผ่น | ในแอป |
|---|---|
| `● ○ —` (แถวล่างสุด) | TIME mode |
| Note | PITCH mode — ใส่ได้เฉพาะช่อง `●` เหมือนเครื่องจริง |
| Accent / Slide | ปุ่มใน Step editor |
| Down / Up | ปุ่ม ▲▼ ข้างคีย์บอร์ด |

ลำดับที่เร็วที่สุดคือทำแบบเดียวกับเครื่องจริง — ไล่แถวจังหวะให้ครบใน TIME mode ก่อน แล้วค่อยกลับมาใส่พิตช์

## เทสต์

```bash
bash test/run.sh
```

ไม่ต้องติดตั้งอะไร ใช้ Node เปล่าๆ · **รันก่อน commit ทุกครั้ง** เทสต์พวกนี้เคยจับบั๊กที่ทำให้หน้าตายเงียบๆ มาแล้วสองรอบ

- `smoke.js` — eval สคริปต์ทั้งก้อนกับ DOM ปลอม จับ error ตอน boot
- `test_dsp.js` — เสียงแต่ละ voice, choke, time data, pattern length, CPU, knob sweep, worklet serialization
- `hash_test.js` — บันทึก/อ่าน URL ทุกเวอร์ชัน รวมลิงก์เก่า
